절차: 새 데이터와 모든 데이터의 거리 d=√((x₁−y₁)²+(x₂−y₂)²+…) 계산 → 가장 가까운 k개를 뽑아 다수결로 소속을 정한다.

수학 포인트: 유클리드 거리(피타고라스 정리의 확장), k는 동점 방지를 위해 홀수, 변수 단위가 다르면 표준화(정규화) 필수.

언제 틀리나: 경계에 걸친 데이터, 한쪽 라벨이 압도적으로 많은 불균형 데이터, 정규화를 빼먹은 경우.

원리 카드 ② K-means — 군집

절차: 중심 k개를 임의로 두고 ① 각 점을 가장 가까운 중심에 할당 → ② 중심을 소속 점들의 평균으로 갱신 → 변화가 없을 때까지 ①②를 반복.

수학 포인트: 목적함수 J = Σₖ Σx∈Cₖ ‖x−μₖ‖² (군집 내 거리 제곱합)를 줄여 가는 과정. 평균(무게중심)이 왜 최적인지는 이차식의 최솟값으로 설명 가능.

언제 틀리나: k를 잘못 고르면 억지 묶음(엘보 기법으로 보완), 초기 중심에 따라 결과가 달라짐, 동떨어진 이상치에 민감.

실습을 수식으로 — KNN·K-means의 엄밀한 정의와 탐구 과정

위 실습에서 손과 눈으로 겪은 것을, 이제 수학의 언어로 승격시킵니다. 탐구 순서는 체험(위젯) → 기록(활동지③) → 수식화(정의) → 증명(왜 평균인가) → 한계 토론 — 공식 교육과정 성취기준 [12인수03-01·02](분류의 수학적 방법), [12인수04-01·02](오차 함수와 최적화)가 바로 이 지점입니다.

정의 1 · KNN (k-최근접 이웃 분류)

학습 데이터 D = {(x1, y1), …, (xn, yn)}, 각 xi는 좌표(소음, 유동인구), yi는 유형 라벨.

① 거리 — 새 점 z와 각 xi의 유클리드 거리:
d(xi, z) = ‖xi − z‖ = √( (xi1−z1)² + (xi2−z2)² )
— 피타고라스 정리의 좌표평면 확장.

② 이웃 집합 — 거리가 가장 작은 k개의 데이터를 Nk(z)로 정의.

③ 판정 규칙(다수결) — ŷ(z) = argmaxc Σi∈Nk(z) 1(yi = c)
— Nk 안에서 라벨 c의 표를 세어 최다 득표 라벨을 채택. k가 홀수면 동점이 없다.

④ 정규화(전제 조건) — 변수 단위가 다르면 거리가 왜곡되므로 x′ = (x − min)/(max − min) 또는 z-점수로 변환 후 거리를 계산한다.

정의 2 · K-means (k-평균 군집)

라벨 없는 데이터 x1, …, xn을 k개의 군집 C1, …, Ck(중심 μ1, …, μk)로 나눈다.

① 목적함수(군집 내 거리 제곱합)
J(C, μ) = Σk Σxi∈Ck ‖xi − μk‖²
— J가 작을수록 "끼리끼리 잘 묶인" 상태. J는 곧 이 문제의 손실함수다.

② 할당 단계 — 각 점을 가장 가까운 중심에: c(i) = argmink ‖xi − μk‖² (μ 고정, J 감소)

③ 갱신 단계 — 중심을 소속 점의 평균으로: μk = (1/|Ck|) Σxi∈Ck xi (C 고정, J 감소)

④ 수렴 논증 — 두 단계 모두 J를 줄이거나 유지하고, J ≥ 0이므로 무한히 줄 수 없다 → 유한 번 반복 후 종료. 위 실습기에서 J가 단조감소하다 멈춘 것이 이 증명의 실험적 증거다.

증명 탐구 · "중심은 왜 하필 평균인가?" — 이차함수와 미분으로 (모둠 유도 활동)

한 군집의 점 x1, …, xm(1차원으로 단순화)에 대해 중심 μ를 어디에 두어야 거리 제곱합이 최소일까?

1단계 — f(μ) = Σi=1m (xi − μ)² 로 두면, 전개 시 f(μ) = mμ² − 2(Σxi)μ + Σxi² : μ에 대한 아래로 볼록한 이차함수.

2단계 — 미분: f′(μ) = −2 Σi=1m (xi − μ). 최솟값에서 f′(μ) = 0 이므로 Σxi − mμ = 0.

3단계 — 따라서 μ = (1/m) Σi=1m xi = x̄ (평균) — ③ 갱신 단계에서 평균으로 옮기는 것이 가장 J를 많이 줄이는 선택임이 증명된다. (2차원이면 좌표별로 같은 논리)

※ 학생 유도 활동: 2단계의 f′(μ)와 3단계의 μ 자리를 빈칸으로 비우고 모둠이 채우게 하세요(활동지③ 뒷면). 이차함수 꼭짓점(수학Ⅰ)·미분(수학Ⅱ)과 직결되며, 4차시 회귀의 최소제곱법, 이후 경사하강법의 손실함수 최소화로 이어지는 다리입니다.
