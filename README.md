# 2026 인공지능 수학 · 우리 동네 데이터 분석·문제 해결 AI 모델 아카이브

대전대신고등학교 3학년 인공지능 수학 프로젝트 **"디지털 코딩 도구를 활용한 우리 동네 문제 해결 AI 모델 형성 및 분석"** 성과 공유 아카이브입니다.

- 출품작 80팀 / 수상 70팀(대상 10 · 최우수 10 · 우수 20 · 장려 30)
- 각 팀: 제목 · 팀원(학번·이름) · 포스터/보고서/전처리/프롬프트 · 핵심 지표
- 상세 수록 팀: 주제 · 데이터 출처·가공 · 수학 원리의 자기주도 탐구 · 대수식 이해 · 모델 검증 · 모델별 수학적 성질
- 포스터·보고서는 **사이트 내 미리보기(열람 전용, 다운로드 불가)**

## 실행
`docs/index.html` 을 브라우저로 열면 됩니다. (단일 HTML, 별도 설치 불필요)

## GitHub Pages 배포
1. 이 폴더를 GitHub 저장소에 올립니다.
2. 저장소 **Settings → Pages → Source: `Deploy from a branch`**, 폴더를 **`/docs`** 로 지정.
3. 발행된 주소(`https://<계정>.github.io/<저장소>/`)로 접속.

## 교사 다운로드 비밀번호
- 사이트 우측 상단 **🔑 교사 로그인** → 비밀번호 입력 시 원본 다운로드가 열립니다.
- 기본 비밀번호: `dshs2026!`  (변경하려면 index.html 상단 스크립트의 PWHASH 값을 새 비밀번호의 SHA-256 해시로 교체)
- 참고: 완전한 다운로드 차단은 구글 드라이브에서 각 파일을 '뷰어 · 다운로드 사용 안 함'으로 설정해야 보장됩니다.
