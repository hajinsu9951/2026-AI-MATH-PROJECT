- ⬜ **반드시 `startup10_제출용.html`을 첨부** (일반 `startup10.html`에는 GitHub 계정명이 있음). 제출용은 성명·학교명·계정명·워크스페이스명 0건 확인 완료.
- ⬜ 캔바 5종 공유 설정 = "링크가 있는 모든 사용자 보기 허용" (특히 「린 비즈니스 모델」·「BMC 튜토리얼」·「첨단ABCDE×AI」)
- ⬜ 드라이브 수상작 파일: 공유 "링크 보기" 유지 + **파일명에 학번·이름이 있으면 파일명만 수정** (썸네일·미리보기에 노출될 수 있음)
- ⬜ (선택) 활동 사진 `photo1~6.jpg` · 증빙 `ev-01~11.jpg`를 docs 폴더에 넣은 경우 → **다시 제출용 파일을 만들 필요 없음** (사진은 같은 폴더에 있어야 표시되므로, 사진 포함 제출 시 html+사진을 zip으로 묶거나 클라우드 링크 방식 사용)
